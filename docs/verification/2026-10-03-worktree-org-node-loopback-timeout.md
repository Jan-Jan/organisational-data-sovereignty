## What was wrong, and what was built

`TransportMode::Loopback` is documented as binding `127.0.0.1`, and the three test targets that use it describe themselves as offline. The builder named no bind address at all, so iroh used its pre-configured wildcard sockets — `0.0.0.0` and `[::]`, which is **every interface the host has**, not merely the LAN one — and `Endpoint::addr()` advertised a non-loopback address. Every "loopback" exchange dialled that address and left the machine.

`git log -L '/pub async fn bind_with_mode/,/^    }/'` shows the Loopback arm has exactly one commit in its history, `2bb1c21`. **This was never a regression.** The code was always wrong and the host's network always decided the outcome: seven end-to-end tests across three targets were green for weeks because the host delivered datagrams addressed to its own LAN address back to itself, and went red together when it stopped.

The fix clears iroh's default IP transports and names both loopback addresses. Naming one is not enough — a bind address replaces the pre-configured wildcard only for its own address family, so binding `127.0.0.1` alone leaves `[::]` on every interface. The IPv6 bind is explicitly **not** required (`BindOpts::default().set_is_required(false)`), because that flag defaults to true and would otherwise abort the endpoint on any host without IPv6, where iroh's own `[::]` default is documented as allowed to fail.

PR-hvg2dy was fixed in this change too, for five of its eight commits, and that work is **not in the merged tree** — `27dab89` resolved the report on `master` first and every conflicting file was resolved in its favour. See the note under `branch:` above. What survives of it here is one sentence in the dependency-expectation and one in the hazard register, both saying what that resolution did *not* change: the decisive input to RC-6a2dke still rests on a provider's doc-comment rather than on an exported requirement, because REQ-ysyu9g is still open.

**The lesson is not about iroh.** A test that asserts an end-to-end outcome cannot distinguish the property it means to test from an accident of the environment that produces the same outcome. The repair is a test that reads the bound sockets and fails on the address, by name, in hundredths of a second, with no network at all — and two requirements, so the contract lives somewhere a gate can see it rather than in a rustdoc comment. That question is worth asking of the other three units' suites, and is booked in the owner register.

### Round 1

## Gaps

What this change did **not** establish. A gap stated here is a gap; a gap left out is a claim.

1. **The relay leg of "confined to this machine" is argued, not asserted.** Loopback mode is confined only if the relay stays disabled as well as the sockets staying loopback, and no gated test can see the difference. A relay home is acquired after `online()`, so an assertion made at bind time cannot observe one; an assertion made after `online()` would measure whether this host can reach a relay, which is the host-dependence this change exists to remove. iroh exposes no relay map on `Endpoint`.
